# Blisspoint - StartOS SDK 3 Package

Blisspoint is a Bitcoin miner-as-space-heater app that runs on StartOS. The app communicates with ASIC miners over the LAN and presents a simple web interface for power control, hashrate monitoring, and temperature display.

Upstream repository: https://github.com/heatpunk/blisspoint

The app is packaged as a StartOS SDK 3 `.s9pk` using a published Docker image from [ghcr.io/heatpunk/blisspoint](https://ghcr.io/heatpunk/blisspoint).
